# 샌드박스 모드 (배틀 데모)

실제 게임에서는 안 되는 조합을 실험하는 모드입니다. **9세대 메커닉** 위에서 돌고(`gen: 9`), 설정·팀은 세대 팀과 따로 저장됩니다.
화면: 짧은 소개 → 프리셋 3개 → "세부 설정" 토글(한 줄 설명).

## 프리셋

| 프리셋 | 켜지는 것 |
|---|---|
| 모든 기믹 겹치기 (기본) | 기믹 겹치기 |
| 손가락흔들기 | 손가락흔들기 |
| 자유 세트 | 기믹 겹치기 + 자유 기술·특성·도구 + 자유 능력치 + 자유 레벨 |

| 토글 | 엔진 / Showdown | 한계 |
|---|---|---|
| 기믹 겹치기 | `options.stackGimmicks` → 엔진 규칙 **Stack Gimmicks Mod** (`src/engine/gimmickrules.ts`) | 아래 |
| 손가락흔들기 | `createMetronomeBattle` (모든 기술 = 손가락흔들기, 랜덤 또는 고른 종, 레벨, 능력치 덮어쓰기) | 다른 토글과 함께 쓰지 않음 |
| 자유 기술·특성·도구 | 엔진은 검증하지 않는다 (기술표 경고를 끄고 모든 기술·특성, 7·8세대에만 있던 메가스톤·Z크리스탈까지 목록에) | 지닌 도구는 하나 |
| 자유 능력치 | 세트 `customStats` → 엔진 **Custom Stats Mod** (1~9999, 지정한 스탯만) | 리플레이에 `p1.stats` 로 따로 실림 (Showdown 텍스트에는 없는 칸) |
| 자유 레벨 | 세트 레벨 1~100 (끄면 모두 Lv.50) | |

### 기믹 겹치기 (Stack Gimmicks Mod)

- 한 포켓몬이 **메가진화(또는 울트라버스트) + 다이맥스 + 테라스탈**을 한 턴에 함께, 또는 턴을 나눠 쓸 수 있습니다. Z기술 + 테라스탈도 됩니다.
- 각 기믹은 그대로 **진영당 한 배틀에 한 번**. 지닌 도구가 하나라 메가스톤과 Z크리스탈(또는 원시회귀 구슬)을 함께 가질 수 없어 메가 + Z 는 안 됩니다.
- **Z기술 + 다이맥스는 안 됩니다**: 다이맥스하면 기술이 다이맥스 기술로 바뀌기 때문 (Showdown 과 같음). 다이맥스 중에도 Z기술 버튼은 나오지 않습니다.
- 순서는 Showdown 행동 큐 그대로: **메가진화(104) → 다이맥스(105) → 테라스탈(106) → 기술**.
- 메가·원시·울트라 모습은 **거다이맥스하지 않고** 그 모습으로 다이맥스합니다 (메가리자몽Y → 다이번). 거다이맥스 모습은 원래 모습에만 있기 때문입니다.
- 메가레쿠쟈(화룡점정)도 됩니다 (9세대 Showdown 은 과거 태그가 있어야 허락).
- 구현: Showdown 이 기믹을 서로 막는 곳을 이 규칙이 있는 배틀에서만 런타임 패치합니다 — `Side.choose`(선택 문자열 `move 1 mega dynamax terastallize` 의 꼬리말 여럿), `Side.chooseMove`(나머지 기믹 검사·표시), `Side.canDynamaxNow`(8세대 밖에서도), `Pokemon.getDynamaxRequest`(메가·Z 도구를 지녀도), `Pokemon.formeChange`(도구로 모습이 바뀌어도 테라스탈 가능 유지, 거다이맥스 끔). 규칙 `onBegin` 은 테라스탈 가능 여부를 도구와 상관없이 다시 정합니다.
- 테스트: 엔진 `src/tests/engine/genrules.test.ts` (한 턴 세 기믹·턴 나눠서·Z+테라·Z+다이맥스 거절·울트라버스트·메가레쿠쟈·입력 로그 재현, 60배틀 퍼즈), 데모 `lib/options.test.ts`.
- 데모 화면: 기술 메뉴의 기믹 버튼이 서로 독립 토글이 되고(Z기술 ↔ 다이맥스만 서로 끔), 모습은 겹쳐 그립니다 (메가 스프라이트 + 다이맥스 크기·붉은 빛 + 테라 배지). CPU(보통·어려움)도 함께 씁니다.

## 하지 않은 것

- **기믹 횟수 제한 해제** (진영당 한 번 → 포켓몬마다 한 번): Showdown 은 기믹 사용을 진영 상태(`side.megaEvoUsed`·`zMoveUsed`·`dynamaxUsed`, `choice.mega` 등)와 모든 아군의 `canMegaEvo`/`canTerastallize` 를 지우는 방식으로 막아서, 포켓몬 단위로 바꾸려면 메가진화·테라스탈 실행 코드까지 덮어써야 합니다. 안전하게 할 수 있는 범위를 넘어 이번에는 뺐습니다.
- **시작 필드 설정** (날씨·필드·트릭룸·장판을 깔고 시작): Showdown 에 해당 규칙이 없고 리플레이 재현까지 맞추려면 새 엔진 규칙이 필요해 뺐습니다.
- 전국도감: 9세대 엔진 데이터의 모든 종(지난 세대에만 있던 종·폼 포함)을 고를 수 있습니다. 메가·거다이맥스 모습은 도감에서 고르지 않고 메가스톤·거다이맥스 체크로 됩니다.
