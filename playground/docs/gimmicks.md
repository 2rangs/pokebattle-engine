# 배틀 기믹 체크리스트 (배틀 데모)

규칙은 엔진(= Pokémon Showdown 시뮬레이터 `@pkmn/sim`)이 정하고, 데모는 요청·이벤트를 그대로 보여 줍니다.
출처: `@pkmn/sim` `sim/battle-actions.ts`(`canMegaEvo`·`canUltraBurst`·`canZMove`·`getMaxMove`), `sim/side.ts`(선택 검사),
`sim/pokemon.ts`(`canGigantamax`), `data/conditions.ts`(`dynamax`), `data/items.ts`(`megaStone`·`zMove`·`itemUser`·`onPrimal`),
`data/text/default.ts` + 클라이언트 `battle-text-parser.ts`(문장).

표: ✅ 처리·테스트 있음 · ☑️ 처리 (시뮬레이터 규칙 그대로, 따로 테스트 없음) · ⚠️ 알려진 한계

## Z기술 (7세대)

| 항목 | 상태 | 어디서 / 테스트 |
|---|---|---|
| 버튼은 `can_zmove`, Z기술이 되는 기술(`moves[i].zmove`)만 누를 수 있음, 한 배틀에 한 번 | ✅ | 엔진 테스트 |
| 기술 버튼이 Z기술 이름·위력으로 (`previewDamage(…, { zmove })` 의 `moveName`·`basePower`) | ✅ | 엔진 `gimmicks.test.ts` 데미지 미리보기 |
| 타입 Z크리스탈 18개 + 전용 Z크리스탈 (피카츄Z·루나아라Z·미밋큐Z… `itemUser`) — 필살피카슛 등 전용 Z기술 이름·위력 | ✅ | 엔진 테스트 (피카츄Z → 필살피카슛 210) |
| "Z파워를 몸에 둘렀다!" → 공격 Z기술은 "전력의 Z기술을 펼친다!" (Showdown `zEffect`) | ✅ | 엔진 테스트 |
| 변화 Z기술 추가 효과: 랭크 상승 "Z파워로 {능력}이(가) 올라갔다", 회복, 떨어진 랭크 되돌림, Z기충전(급소) | ✅ | 엔진 테스트 (Z초롱초롱눈동자 방어↑) |
| Z저주: 고스트는 HP 회복 효과, 그 밖은 공격↑ | ✅ | 엔진 테스트 |
| 방어를 뚫은 Z기술 "완전히 막지 못하고" (`-zbroken`) | ☑️ | 문장 있음 |
| 연출: `z-symbol.png` + 금빛 | ✅ | 스크린샷 `gimmick-z-*.png` |

|---|---|---|

| 3턴 (`turns_remaining` 3→2→1), HP 2배 (최대 HP 변화는 문장 없는 `source: 'dynamax'`) | ✅ | 엔진 테스트, `lib/gimmick.test.ts` |

| 거다이맥스: 세트 `gigantamax` (Showdown `Gigantamax: Yes`, 랜덤 8세대 세트 유지) → "거다이맥스했다!", 거다이맥스 기술 (예: G-Max Wildfire) | ✅ | 엔진 테스트, `lib/gimmick.test.ts` |

| 끌어내기 막힘 "다이맥스의 힘에 막혔다!", 풀죽음 무효·다이맥스 기술 추가 효과(날씨·필드·랭크) | ✅ / ☑️ | 엔진 테스트 (날려버리기), 나머지는 시뮬레이터 |
